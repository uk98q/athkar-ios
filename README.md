# أذكار

تطبيق أذكار لآيفون، خفيف وحديث، بواجهة Liquid Glass وخلفية سوداء OLED وخط Readex Pro. كل المزايا مجانية، ولا توجد اشتراكات ولا مشتريات داخل التطبيق.

التطبيق مخصص للاستخدام الشخصي، وليس موجوداً في App Store.

## الأقسام

- **الرئيسية**: تقترح قسم الصباح أو المساء حسب الوقت، مع بطاقات لكل الأقسام ونسبة إنجاز كل قسم.
- **الأذكار**: أذكار الصباح، وأذكار المساء، وبعد الصلاة، والنوم، وعند الاستيقاظ، ودعاء السفر، وأدعية متنوعة، وأسماء الله الحسنى (99 اسمًا).
- **المسبحة**: عداد إلكتروني بأهداف 33 أو 99 أو 100 أو بدون هدف، مع إجمالي للعدّ وتصفير.
- **الإعدادات**: حجم الخط، والاهتزاز عند العد، وتصفير تقدم اليوم.

## المميزات التقنية

- الواجهة من اليمين لليسار، ومظهر داكن كامل.
- التقدم يُحفظ على الجهاز فقط لليوم الحالي، ويتصفّر تلقائياً في اليوم التالي.
- تأثير Liquid Glass على iOS 26 فما فوق، وبديل بخلفية ضبابية على الإصدارات الأقدم.
- الحد الأدنى iOS 17.

## طريقة التثبيت

التطبيق يأتي بملف IPA غير موقّع، لذلك تحتاج أداة تثبيت تُعيد توقيعه باسم حسابك:

1. نزّل ملف `Athkar-v1.1-build<رقم>-unsigned.ipa` من صفحة الإصدارات (Releases) في هذا المستودع. كل نسخة لها إصدار منفصل، والنسخ القديمة تبقى متاحة.
2. ثبّته بإحدى الطريقتين:
   - **LiveContainer**: ثبّت LiveContainer على الآيفون، افتحه، اضغط علامة `+` واختر ملف الـ IPA، ثم افتح التطبيق من داخله.
   - **Sideloadly**: من الكمبيوتر، وصّل الآيفون، واسحب ملف الـ IPA إلى Sideloadly، وسجّل الدخول بحساب Apple، ثم اضغط Start.
3. إذا استخدمت حساب Apple مجاني، يحتاج التوقيع إلى تجديد كل 7 أيام عبر الأداة نفسها.

## البناء التلقائي

كل دفعة (push) على فرع `main` تُشغّل GitHub Actions على جهاز macOS مجاني، فتبني الـ IPA غير الموقّع وتنشره في إصدار جديد.

لبناء المشروع محلياً على Mac:

```bash
brew install xcodegen
xcodegen generate
open Athkar.xcodeproj
```
